# STG-стенка в сплошном упругом теле

Это отдельная постановка, не массив свободных кирпичиков в воде. Слева и
справа — алюминиевый континуум; 13 перемычек соединены с ним по торцам.
Вырезы и промежутки не сетятся: их стенки свободны от нагрузки.
Используется исправленный STG со сдвинутыми профилями, общей толщиной H−A,
а не симметричные встречные сужения. Все значения API — SI.

## Уравнения и границы

Линейная изотропная упругость, 2D **плоская деформация**, неизвестное u=(uₓ,uᵧ):

```
ρ ü − div σ = f
σ = λ tr(ε) I + 2 μ ε,    ε = (∇u + ∇uᵀ)/2
μ = E/[2(1+ν)],           λ = Eν/[(1+ν)(1−2ν)]
```

Свободные стенки: σn=0 (естественное условие слабой формы). На внешнем
прямоугольнике локальное поглощающее условие первого порядка:

```
σn = −ρ [cₛ I + (cₚ−cₛ) n⊗n] u̇
cₚ²=(λ+2μ)/ρ,   cₛ²=μ/ρ
```

Это приближение для выходящих волн, не PML. В одноячейковой калибровке
верхняя и нижняя внешние стенки свободны, поглощают только торцы.
Материальные потери отсутствуют. Здесь нет тонкой пластины, Lamb- или SH-мод.

P1 FEM даёт симметричные M,K,C: `M ü + C u̇ + K u = f(t)`.
Стационарный расчёт с соглашением exp(−iωt):
`(K−ω²M−iωC) û = f̂`. Поглощённая внешней границей мощность
`ω² Re(ûᴴCû)/2` сравнивается с принятой `Re(iω ûᴴ f̂)/2`.
Импульс интегрируется Newmark β=1/4, γ=1/2 с балансом
`энергия внутри + ушедшая энергия = работа источника`.

Источник — распределённая объёмная сила, нормированная по интегралу в
левом массиве: Gaussian по x, cos²(πy/H) по y. `source_strength` имеет
размерность N/m (на единицу внеплоскостной длины). Вертикальная сила
создаёт преимущественно SV-падение, горизонтальная — преимущественно P;
конечная апертура и рассеяние допускают смешение мод. Название возбуждения
не означает, что всё поле — одна чистая мода.

## Проектирование не заменяет расчёт всей линзы

`design_stg_lens` сначала решает 27 настоящих одноячейковых FEM-задач:
A=0:0.6:4.8 mm, N=1,2,3; L=17 mm, H=7 mm. Комплексная передача — отношение
выбранной компоненты смещения к сплошному калибровочному волноводу на том
же сечении. **Это не энергетический S21.** Кандидаты с |T|≤0.15 исключены.

Для центра каждой ячейки y выбирается фаза `−k(√(F²+y²)−F)` с общей свободной
фазой и мягким штрафом за малую передачу. По умолчанию проектирование
выполняется для SV, 140 kHz, F=40 mm после выходного торца. Калибровка не
учитывает взаимодействие соседей в полном массиве. Поэтому отдельно
рассчитывается вся соединённая стенка — только это поле используется в UI.

При смене частоты или возбуждения в Pluto **геометрия не перепроектируется**.
Это опыт по расстройке одной линзы. TOML сохраняет все реальные параметры
13 ячеек, а CSV проектирования — выбранные передачи и фазовые ошибки.
Старые 140-kHz амплитудные коэффициенты и результаты отдельной 242-kHz
линзы не используются как входы или доказательства этой модели.

## Шесть фиксированных опытов

1. Сплошной алюминий: контроль без прорезей.
2. Прямые перемычки: та же длина и **масса каждой** выбранной STG-ячейки.
3. Одинаковые STG: проверка, достаточна ли одинаковая извилистость; L/H и
   торцевой отступ сохраняются, A/H=5/14, N=2.
4. Расчётная STG-стенка: фазовая расстановка из калибровки.
5. Перемешанные STG: те же самые ячейки и суммарная масса, порядок сдвинут
   циклически на три позиции.
6. Отсутствующая центральная перемычка: изменение структуры; эффект не
   обязан ухудшать каждую метрику.

Все контроли имеют одинаковые материал, источник, частоту, область и
номинальные размеры сетки. «Одинаковые STG» имеют другую массу и не
подменяют равно-массовый прямой или перемешанный контроль.
Прямой контроль строится из фактически выбранных ячеек, включая удаление и
перестановку. Для двух этих вариантов отдельно показана исходная полная линза.

## Что показывает график

На сечении x=L/2+F и 41 сечении справа вычисляется P1-интерполяция обеих
компонент. Средняя кинетическая плотность `⟨K⟩=ρω²(|ûₓ|²+|ûᵧ|²)/4`, J/m³.
UI делит её на принятую мощность W/m, размерность профиля — s/m². Все
кривые имеют одну шкалу: независимого растяжения пиков до единицы нет.
Карта использует ту же нормировку; насыщение цвета явно подписано.

FWHM — ширина связного главного пика на половине его максимума с линейной
интерполяцией пересечений. Если сечение не содержит оба пересечения,
возвращается NaN. При смене сильнейшего лепестка ширина может прыгать;
это не автоматически перемещение физического фокуса. Узкий пик надо
смотреть вместе с полной картой, боковыми лепестками и контролями.

Профиль не равен потоку энергии, коэффициенту передачи, SV-мощности или
разрешению NDT. Модового P/SV-разложения и измерения рассеяния здесь нет.
Гармоническая перемотка — изменение фазы установленного поля, не прибытие
волны; отдельный `simulate_pulse` показывает настоящий переходный процесс.

## Библиотека и воспроизведение

```julia
using MetaNDT, Gridap, GridapGmsh, Gmsh
d = design_stg_lens(SolidLensExperiment())
s = solid_preset(d, :focused)
r = simulate(s)
p = simulate_pulse(s)
save_experiment("lens.toml", s)
replay = simulate(load_experiment("lens.toml"))
write("profile.csv", solid_profile_csv(r))
write("cells.csv", lens_design_csv(d))
```

`SolidLensExperiment → simulate / simulate_pulse → plain-array Result` не
зависит от Pluto или визуализации. Gmsh/OCC объединяет левый и правый
массивы с перемычками: это одна связная сетка, а не склеенные только на
рисунке элементы. `missing_cells` убирает перемычку из геометрии.

CAD-контракт кирпичиков: конечные размеры, минимальная толщина и сегменты
профиля не меньше 1 µm; торцевой отступ либо ровно ноль, либо ≥1 µm.
Отступ 1e−10 m отвергается до Gmsh с `ArgumentError`; форму молча не
исправляем. Нулевая сила допустима и даёт нулевое поле, но калибровка фаз
без сигнала не определена.

Для научных выводов нужны уточнение сетки и полилинии профиля, проверка
временного шага и внешней границы. Текущая проверка приведена отдельно в
[SOLID_LENS_VALIDATION.md](SOLID_LENS_VALIDATION.md). Возможные следующие
сюжеты, включая настоящий scattering/cloaking, описаны в
[NEXT_PHYSICAL_SCENARIOS.md](NEXT_PHYSICAL_SCENARIOS.md).
