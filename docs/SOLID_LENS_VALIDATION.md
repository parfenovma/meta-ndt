# Проверка solid STG-стенки

Локальный прогон 15 октября 2026 года: Julia 1.10.12, Gridap 0.20.10,
GridapGmsh 0.7.4, Gmsh.jl 0.3.1, macOS ARM64. Межплатформенный CI настроен,
но этот документ не выдаёт локальный запуск за результат GitHub Actions.

## Замороженный опыт

`design_stg_lens(SolidLensExperiment())`: SV-возбуждение, 140 kHz,
13 ячеек L=17 mm, H=7 mm, цель F=40 mm после стенки. Область 180×112 mm;
E=70 GPa, ν=0.33, ρ=2700 kg/m³. Номинальный h=1.2 mm вдали, 0.5 mm у
стенки; фазовая калибровка по 27 кандидатам, без ручных коэффициентов эха.
Максимальная ошибка выбранной одноячейковой фазы 0.287 rad — это качество
приближённого проектирования, не ошибка полного FEM-решения.

Сечение x=48.5 mm, y=−50.4…50.4 mm, 301 точка. FWHM относится к полной
средней кинетической плотности, а не к отдельно выделенной SV-волне.

| Конструкция | FWHM, mm | y главного пика, mm | Пик / принятая мощность, s/m² |
|---|---:|---:|---:|
| Сплошной массив | 46.706 | 0.672 | 0.001532 |
| Прямая стенка той же массы | 20.138 | 0.000 | 0.003021 |
| Одинаковые STG | 43.797 | −0.336 | 0.000823 |
| Расчётная STG-стенка | 17.639 | 1.008 | 0.002355 |
| Перестановка тех же STG | 36.759 | 21.504 | 0.001253 |
| Без центральной перемычки | 17.601 | 0.672 | 0.002466 |

Площадь STG и прямой стенки одинакова: 0.0192283165714 m²; перемешанная
стенка сохраняет эту же площадь. Одинаковые STG — другая масса.
Линейные невязки <3e−12, дисбаланс мощности <1e−13.

**Ограниченный вывод:** рассчитанная STG-расстановка даёт более узкий
приосевой пучок в целевом сечении, чем эти контроли. Прямая стенка тоже
сильно сужает пучок и имеет **больший нормированный пик**. Удаление одной
перемычки не ухудшает FWHM. Поэтому «STG лучше всегда», «дефект обязательно
ломает линзу» и «получен выигрыш NDT» из опыта не следуют.

## Уточнение и граница

- При h=1.0 mm / 0.35 mm: STG 18.378 mm, прямой контроль 20.131 mm.
  Ширина STG меняется на 4.2%; порядок сохраняется, y=1.008 mm.
- При ширине области 240 mm (высота, источник и целевое сечение прежние):
  STG 17.654 mm, прямой контроль 19.935 mm. Это проверка удаления торцевой
  границы, не доказательство отсутствия всех отражений от боковых границ.
- Пространственная карта и 41 сечение показывают также боковые лепестки.
  Глобальная FWHM может прыгать при смене главного лепестка; минимум всех
  ширин не используется как автоматическое «доказательство фокуса».

## Настоящий импульс

Окно sin², 6 периодов, 140 kHz; длительность расчёта 140 µs, шаг 0.1 µs.
FWHM профиля кинетической плотности, интегрированной по **всем временным
шагам**, а не только отображаемым кадрам:

- сплошной массив — 46.523 mm;
- прямая стенка — 20.978 mm;
- STG — 17.675 mm.

Принятая работа STG 4.7676e−12 J/m. Баланс энергии <1e−13.
Это отдельный transient FEM; гармоническая анимация фаз не использовалась
в качестве временного результата.

## Автоматические проверки

Из соседнего `meta-demo`:

```bash
julia --startup-file=no --project=demo ../meta-ndt/test/solid_fem.jl
julia --startup-file=no --project=demo test/solid_ui.jl
julia --startup-file=no --project=demo test/review_regressions.jl
julia --startup-file=no --project=demo ../meta-ndt/test/solid_api_regressions.jl
```

`solid_fem.jl` проверяет параметры, CAD-минимум, независимое affine
воспроизведение P1-интерполяции, TOML всех шести опытов, площади, связность
настоящей FE-сетки, симметрию M/K/C, энергетический баланс, линейность,
уточнение сетки и удаление торцевой границы. Для импульса дополнительно
проверяет нулевое начальное поле и изменение профиля при уменьшении шага.

Два прежних P2 имеют отдельные регрессионные тесты: прямой контроль
сравнивается с **упругим** STG даже при входном `scenario=:rigid`; микроскопический
положительный торцевой отступ отвергается до Gmsh, ровно нулевой остаётся
разрешён. Общий ускоренный семплер также прогоняется на прежних водных
задачах; самостоятельный проход UI проверяет кэш и фактические контроли.
После независимого ревью добавлены регрессии для одинаковых STG нестандартного
размера, скана в коротком правом массиве и прямых контролей реально выбранной
uniform/переставленной/дефектной стенки. Для последних двух отдельно сохранён
также полный исходный STG-контроль. Проверка перестановки использует пять
различных ячеек, чтобы сдвиг на три не оказался тождественным.

Это проверка конкретного MVP, не сертификация инженерного решателя:
остаются расширенная сходимость геометрии/сетки, проверка сторон области,
модовые потоки и экспериментальная валидация. Уменьшение ширины пучка не
является измерением пространственного разрешения дефектоскопии.
